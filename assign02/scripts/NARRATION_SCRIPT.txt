[STEP 2: COMPUTING MERKLE ROOT & DOMAIN SEPARATION]
--------------------------------------------------------------------------------
COMMAND TO RUN:
python -m merkle.cli root "tx1" "tx2" "tx3" "tx4" "tx5"

SPOKEN NARRATION:
"First, we calculate the Merkle root for a set of 5 transactions: 'tx1' through 'tx5'.
Notice two key architectural properties:
First, cryptographic domain separation: leaves are prefixed with byte 0x00, and internal nodes with byte 0x01. This strictly prevents second-preimage attacks.
Second, odd-leaf handling: when a layer has an odd count like 5, the solitary node is promoted directly to the next level without duplicate hashing, avoiding CVE-style transaction duplication vulnerabilities."

--------------------------------------------------------------------------------
[STEP 3: GENERATING AN INCLUSION PROOF]
--------------------------------------------------------------------------------
COMMAND TO RUN:
python -m merkle.cli prove --index 2 "tx1" "tx2" "tx3" "tx4" "tx5" --out proof.json

SPOKEN NARRATION:
"Next, we generate a cryptographic inclusion proof for leaf index 2, which corresponds to 'tx3'.
Notice the JSON format output:
It contains the leaf index 2, total tree size 5, and an ordered list of sibling hashes with their left or right orientation directions.
This proof provides the logarithmic authentication path needed to reconstruct the exact root."

--------------------------------------------------------------------------------
[STEP 4: INDEPENDENT PROOF VERIFICATION (SUCCESS PATH)]
--------------------------------------------------------------------------------
COMMAND TO RUN:
python -m merkle.cli verify --leaf "tx3" --proof proof.json --root <ROOT_HEX>

SPOKEN NARRATION:
"Now, we independently verify this proof using only the original leaf data, the proof JSON file, and the expected Merkle root.
The verifier reconstructs the parent hashes up the branch.
As you can see: VERIFICATION SUCCESS!
The proof confirms cryptographically that 'tx3' is authentic and included in the Merkle root."

--------------------------------------------------------------------------------
[STEP 5: TAMPER DETECTION & ATTACK REJECTION]

COMMAND TO RUN:
